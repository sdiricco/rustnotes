Notes that stay yours.

A simple notes app in the spirit of Apple Notes, for macOS, Windows and Linux. Everything lives on your disk. Free and open source, no account, no cloud.

Just notes.

The things a notes app should do, done quietly.

Rich text, no fuss

Headings, lists, checklists, tables, images and code blocks with syntax highlighting.

Folders, favorites, trash

Multi-select, drag to reorder, instant full-text search across every note.

Markdown in and out

Import a .md file, export one note or your whole library as Markdown files.

Eight languages

English, Italian, Spanish, French, German, Portuguese, Chinese, Japanese. Follows your system.

Light and dark

Follows your system, or pick one. Zoom the whole interface from the View menu.

Small and native

A Tauri app on the system webview: a few megabytes installed, one process, no bundled browser.

Claude, optional

Fix, rephrase, summarize, continue or ask anything about a selection, with a before/after diff. Uses the Claude Code CLI already on your Mac: no API key, nothing in the app.

Your data is a folder.

One JSON file per note, on your disk, in a folder you can move.

No account, no server

RustNotes never phones home, except for one anonymous request to GitHub to check for a newer version. The optional Claude assistant sends only the text you hand it, through your own Claude Code login. There is nothing to sign up for and nothing to lose access to.

Sync the way you already do

Point the notes folder at iCloud Drive, Dropbox or Syncthing from Settings and use the same notes on every computer. A second machine pointed at the same folder simply adopts it.

Install

Download from the button above, or use Homebrew on macOS.

# Homebrew (macOS)
brew trust sdiricco/rustnotes      # once, required for third-party taps
brew install --cask sdiricco/rustnotes/rustnotes

The honest part

  • The app is not code-signed. Certificates cost money every year and RustNotes is free and stays free. On macOS, right-click the app → Open the first time, or run xattr -dr com.apple.quarantine "/Applications/RustNotes.app". Windows shows a SmartScreen warning.
  • Windows and Linux builds are produced by CI but not yet tested by a human. They compile, they should run, and bug reports with screenshots are very welcome.
  • The Claude assistant needs Claude Code installed and signed in, and uses your Claude subscription. Without it the button is simply not there. Notes with images or tables go through Markdown on the way to Claude: prefer working on a selection there.
  • This is a 0.x release. It is used daily on macOS by its author. Treat it as a public beta elsewhere.
